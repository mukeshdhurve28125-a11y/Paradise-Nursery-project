# Paradise Nursery - Online Plant Shopping Application

Welcome to **Paradise Nursery**, a modern, interactive React dynamic web application designed for online houseplant shopping. This application allows plant enthusiasts to seamlessly browse through various categories of houseplants, view detailed item information, manage their shopping cart, and seamlessly track total costs.

## Features

- **Landing Page:** Welcomes users with a customized background image, company overview, and a "Get Started" call-to-action button.
- **Product Listing Page:**
  - Displays houseplants categorized into multiple groups (e.g., Air Purifying, Aromatic, Medicinal).
  - Features dynamic "Add to Cart" buttons that update item counts and disable automatically once an item is added.
  - Interactive navigation bar displaying the dynamic total item count in the shopping cart.
- **Shopping Cart Page:**
  - Dynamic cost calculation displaying unit prices, individual item sub-totals, and the overall order total.
  - Controls to easily increment, decrement, or delete items from the cart.
  - Working navigation links to return to product browsing ("Continue Shopping") or simulate checkout.

## Technologies Used

- **React.js:** Front-end component framework.
- **Redux Toolkit:** State management for the global shopping cart state.
- **CSS3:** Custom styling and dynamic responsive design.
- **JavaScript (ES6+):** Application functionality and dynamic updates.
